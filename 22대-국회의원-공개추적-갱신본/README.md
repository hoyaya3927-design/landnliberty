## 모바일 대응 (2026-11-07)
- 760px 이하에서 `index.html` 명부는 표 대신 **인물별 카드**로 전환됩니다(정당 컬러 좌측 바 + 이름/정당 헤더 + 2×2 수치 그리드).
- 의원 페이지의 발의법안 목록은 2줄 행, `bills.html`은 2줄 카드, `cases.html`은 항목별 스택으로 재배치됩니다.
- 검색 입력은 iOS 자동 확대를 막기 위해 16px, 필터는 1열 검색 + 2열 셀렉트 그리드.
- 스타일은 `mobile.css` 내용이 각 페이지 `<head>`의 `<style id="mobile-refine">`로 인라인되어 있으며, 원본 소스는 이 폴더 밖 `../mobile.css`입니다(재주입: `python3 apply_mobile.py`).
